## Условия задания
Вариант 6\
Вычислите с использованием цикла for значение ряда, для заданных пользователем значений a и n\
𝑎(𝑎 − 𝑛)(𝑎 − 2𝑛) … (𝑎 − 𝑛^2)

n = 4
Значение ряда = 3360
```

Входные данные:

```
## 1. Алгоритм и блок-схема
### Алгоритм:
1. Начало
2. Объявление переменных a, n, s
3. Инициализация s
4. Вывод: "Введите значения a и n"
5. Ввод переменных a и n
6. Цикл: k = 0; k <= n; k++
6.1 Тело цикла:\
    s = s * (a - k * n)
7. Вывод значения ряда s
8. Конец

## 2. Реализация программы
```c
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_CTYPE, "");

     task();
}

int task()
{
    // Контрольный пример 1
    // a = 2
    // n = 4
    // Значение ряда = 3360

    // Контрольный пример 2
    // a = -4
    // n = 2
    // Значение ряда = -192

    int a, n;
    int s = 1;

    puts("Введите значения a и n");
    scanf("%d %d", &a, &n);

    for (int k = 0; k <= n; k++)
    {
        s = s * (a - k * n);
    }
    printf("Значение ряда равно %d при a = %d и n = %d\n", s, a, n);
}
```
